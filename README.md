# Renewable Energy Storage Readiness Framework (RESRF)

## Overview

The Renewable Energy Storage Readiness Framework (RESRF) is a data analytics project that explores India's renewable energy landscape through an integrated, state-level analytical framework.

The project consolidates renewable energy capacity, electricity generation, resource potential, electricity demand, demographic indicators, and policy-related information from multiple official government sources into a unified dataset. Using interactive visualizations, the framework aims to support evidence-based analysis of renewable energy deployment and identify regions that may require future Battery Energy Storage System (BESS) investments.

---

## Project Objectives

- Build a unified state-level renewable energy database.
- Integrate data from multiple official government sources.
- Develop meaningful analytical indicators for state-wise comparison.
- Design an interactive Power BI dashboard for decision support.
- Create a scalable framework that can be updated as new data becomes available.
